# itf (Insert To File)

`itf` is a command-line tool, now part of the [Coder Suite](https://github.com/sokinpui/coder), that parses markdown code blocks and diff outputs generated by LLMs, and safely applies those changes directly to your local codebase. It parses, fixes, and applies edits, creations, renames, and deletions with built-in transactional **undo** and **redo** capabilities.

`itf` eliminates the friction of manual copying/pasting and patching, serving as the execution bridge in human-in-the-loop AI coding environments.

## Features

- **Markdown Parser**: Extract structured commands from standard LLM responses.
- **Diff Patching**: Intelligently parses standard Unified Diffs and handles context corrections when LLMs slightly hallucinate line numbers.
- **File Lifecycle Actions**:
  - **Create / Modify**: Via path-hinted code blocks.
  - **Delete**: Via `delete` code blocks.
  - **Rename**: Via `rename` code blocks.
- **Transactions & Undo/Redo**: Maintains local operations state at `.itf/` to safely undo (`-u`) or redo (`-r`) file changes.
- **Progress Tracking**: Real-time progress updates with a lightweight TUI indicator.
- **Extensible API**: Fully functional Go library to embed parsing and execution into custom developer tools.

## Installation

### Via Go directly

```bash
go install github.com/sokinpui/coder/cmd/itf@latest
```

### From Source (inside the Coder repository)

```bash
go build -o itf ./cmd/itf
mv itf /usr/local/bin/ # Or any directory in your $PATH
```

## Usage

### Basic Workflow

1.  Copy markdown content containing file blocks or diff blocks.
2.  Run `itf` in your terminal.

```bash
# Read from clipboard
itf

# Read from stdin
cat content.md | itf
pbpaste | itf # on macOS
```

### Input Formats

#### 1. Creation and Modifying (File Blocks)

A standard markdown code block preceded by the path wrapped in backticks or Markdown headings:

````markdown
`src/hello.go`

```go
package main

func main() {
    println("Hello, ITF!")
}
```
````

#### 2. Editing (Diff Blocks)

Standard Unified Diff code blocks are parsed and patched automatically:

````markdown
```diff
--- a/src/main.go
+++ b/src/main.go
@@ -1,5 +1,5 @@
 package main

 func main() {
-	println("Hello, ITF!")
+	println("Hello, World!")
 }
```
````

#### 3. Rename Actions

Rename multiple files concurrently via a `rename` code block:

````markdown
```rename
src/old_name.go src/new_name.go
```
````

#### 4. Delete Actions

Clean up obsolete files via a `delete` code block:

````markdown
```delete
path/to/obsolete_file.go
```
````

### Command-Line Flags

- `-e, --extension`: Filter block operations by extension (e.g., `-e go`). Use `-e diff` to enforce diff-only mode.
- `-f, --file`: Restrict operations to specific target files only.
- `-u, --undo`: Undo the last performed state operation.
- `-r, --redo`: Reapply the last undone operation.
- `-o, --output-diff-fix`: Output corrected unified diff strings only (dry run).
- `--no-animation`: Disables progress animations and loading spinners.

## Developer & Library API

`itf` is modularly structured and can be imported directly into other Go applications:

```go
import "github.com/sokinpui/coder/pkg/itf"

config := itf.Config{Extensions: []string{".go"}}
results, err := itf.Apply(markdownContent, config)
```
